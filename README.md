# Сборщик логов
Скрипт читает `/var/log/syslog`, отбирает строки со словами `error`/`fail` и записывает их в
`report.txt`.

Скрипт упакован в Docker-образ. Для запуска также добавлен Docker Compose.

На Multipass-машине настроено учебное хранилище:

- RAID 1 из двух loop-устройств, смонтирован в `/mnt/raid`;
- LVM-том `lv_logs` размером 200 МБ, смонтирован в `/mnt/logs`.
